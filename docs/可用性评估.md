## 本轮已修

### 高优先（课堂硬需求）

1. **禁止本地模型未下载时静默回退系统 ASR**  
2. **录音改存 `filesDir/recordings`**，同路径 `saveOrUpdate` 防重复  
3. **录音前台服务**（麦克风 FGS + 通知权限）  
4. **模型就绪仅看磁盘**；共享 SenseVoice 包卸载同步别名  
5. **半实时无 VAD 时 UI 提示**  
6. **清空会话清会话指针**；采集端单次增益（减双重 AGC）  
7. **P0：PCM/WAV 磁盘流式落盘**  
   - `StreamingPcmRecorder` / `WavRecorder` 边录边写，停止时回写 WAV 头  
   - `LocalOnnxSession` 结束后按文件分片推理（`transcribeWavFileSegmented`）  
   - 半实时尾巴只读磁盘区间，不再 `ArrayList<Short>` 堆整堂课  
   - 录音管理「重转写」同样按文件分片，避免 OOM  
8. **系统 ASR 路径并行落盘 WAV**，可归档 / 远端重转写  
9. **录音中电平表**；麦克风权限拒绝可跳转系统设置  

## 闪退修复（2026-08-19）

红米 Turbo3 日志：`Ort::Exception … model.int8.onnx … Protobuf parsing failed` → **进程 abort**。  
半实时停顿不出字、后置点停止闪退，同因：损坏/截断的 SenseVoice 权重在 native 加载时崩掉。

已做：体积+伪 HTML 校验、损坏标「已损坏」、强制「重新下载」、开录前预加载（Kotlin 层失败不再进 native）。

## 推荐课堂配置

1. 下载 **SenseVoice ONNX** + **Silero VAD**（模型页独立组件）  
2. 选用 SenseVoice；半实时；切片 4–6s；拾音「课堂」或「远场」  
3. 看电平条确认远场有能量；智能页按需配 LLM；加工后到纠偏页审核 AI 提议词  
4. 录音页管理回听 / 重转写  

## 结论

产品已具备**整堂课试点**所需的内存与归档底座。建议在小米 Turbo 3 上做一次 **40–45 分钟**真实课堂压测（半实时 + SenseVoice + VAD），确认息屏存活与转写质量后再推广。
