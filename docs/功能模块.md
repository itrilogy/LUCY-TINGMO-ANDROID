# 听默 Android · 功能模块与数据流

产品定位：课堂录音 → 本地/远端转写 → 纠偏 →（可选）AI 润色。

## 1. 底栏模块一览

| 模块 | 职责 | 关键依赖 |
| --- | --- | --- |
| **撰写** | 选模式录音/听写、出字幕、AI 加工、清空 | 模型就绪、麦克风、可选 VAD |
| **录音** | 归档 WAV 回听、重命名、删除、重转写 | `filesDir/recordings` |
| **模型** | 下载/移除 SenseVoice·Whisper、独立 Silero VAD | GitHub sherpa-onnx 发行包 |
| **纠偏** | 词库增删、启用；审核 AI 提议词 | Room |
| **智能** | 远端 ASR、大模型、提示词 | 网络 + API Key |
| **关于** | 品牌说明 | — |

## 2. 转写三模式（撰写页）

```
开始录音
  ├─ 实时     → 仅系统 SpeechRecognizer（小米常不可用）
  ├─ 半实时   → 本地 ONNX +（优先）VAD 停顿切段 /（否则）时间窗
  └─ 后置     → 只录 WAV，停止后按策略窗整文件分片推理
停止
  └─ 纠偏词自动套用 → 归档录音 → 可再点「AI加工」
```

### 半实时切段策略（重要）

| 条件 | 行为 | UI 提示 |
| --- | --- | --- |
| 已装 **sherpa 版** `silero_vad.onnx`（约 630KB）且加载成功 | 停顿出片 + 最长切片滑杆 | `半实时·VAD停顿切段` |
| VAD 未装 / 损坏 / 误下 v5 | **回退时间窗**（滑杆秒数） | `半实时·时间窗切段` |

**选型说明（不是随便下个 Silero）：**

- ✅ `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/silero_vad.onnx`（~630KB）
- ❌ Silero 官方 / `silero_vad_v5.onnx`（~2.3MB）——与当前 sherpa-onnx 1.13.6 JNI 不匹配，易乱切、乱字

## 3. 本地 ASR 链路

```
麦克风 → StreamingPcmRecorder（磁盘流式 WAV + 块级增益）
       → 半实时：VAD/时间窗切片 → SenseVoice/Whisper ONNX
       → 后置：停止后 transcribeWavFileSegmented（按文件读窗，防 OOM）
       → CorrectionApplier（纠偏词）
       → RecordingRepository.saveOrUpdate
```

长课保活：`RecordingForegroundService`（麦克风 FGS + 通知）。

## 4. 远端 ASR（智能页）如何配置与使用

### 配置项

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| 启用开关 | 关闭则完全不走云端语音 | 开 |
| Base URL | 到 `/v1` 为止 | `https://api.openai.com/v1` |
| API Key | Bearer Token | `sk-...` |
| ASR 模型 | multipart 字段 `model` | `whisper-1` |

实际请求：

```http
POST {BaseURL}/audio/transcriptions
Authorization: Bearer {API Key}
Content-Type: multipart/form-data
  file = tingmo_xxx.wav
  model = whisper-1
  language = zh
```

兼容任意 OpenAI 风格网关（Groq、自建 whisper 代理等），只要路径与字段一致。

### 何时会调用远端 ASR

| 入口 | 条件 |
| --- | --- |
| 撰写页 **AI加工** | 开关开 + 有本场 WAV → **先云端重转写**，再纠偏，再（可选）LLM |
| 录音页 **重转写** | 开关开 + Key 有效 → 优先远端；否则本地 ONNX |

**不会**在半实时本地字幕过程中边说边调远端（课堂离线优先）。

### 推荐用法

1. 课堂：本地 SenseVoice 半实时出稿  
2. 课后：智能页打开远端 ASR → 回到撰写点「AI加工」，或在录音页「重转写」用云端精修  

## 5. AI 加工完整流水线

```
AI加工
  ├─ [可选] 远端 ASR 重转写整段 WAV
  ├─ 纠偏词库（长词优先）
  ├─ [可选] LLM 按默认提示词润色
  ├─ 再套一遍纠偏词
  └─ [可选] LLM 提议增量纠偏词 → 纠偏页「待审」
```

## 6. 模型与组件

| 资源 | 作用 | 校验 |
| --- | --- | --- |
| SenseVoice INT8 | 中文主力离线 ASR | `model.int8.onnx` ≥ ~200MB |
| Whisper Tiny | 多语轻量 | encoder/decoder 完整 |
| Silero VAD（sherpa） | 半实时停顿切段 | 500KB–1.2MB，拒 v5 |

损坏权重会标「已损坏」，开录前预加载失败只提示、不进 native abort。

## 7. 逻辑连贯性检查清单

1. 半实时状态栏应显示 **VAD停顿切段** 或 **时间窗切段**（可确认是否真启用了 VAD）  
2. 无 VAD 仍可半实时（时间窗），不应当作故障  
3. VAD 乱字 → 先确认文件约 630KB；移除后点「重新下载 VAD」  
4. 远端 ASR 未开时，「AI加工」只做纠偏 +（可选）LLM  
5. 录音始终落 `filesDir/recordings`，与缓存无关  

## 8. 推荐课堂配置

1. 模型页：SenseVoice 完整下载 + Silero VAD（sherpa 版）  
2. 撰写：SenseVoice · 半实时 · 切片 4–6s · 拾音「课堂」  
3. 状态栏确认「VAD停顿切段」  
4. 课后按需开远端 ASR / LLM 做 AI加工
